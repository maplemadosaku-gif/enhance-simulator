# 強化コストシミュレーター

ゲームの強化（★36→41）で、ラッキーデー書を使うかどうか、使うならどの書がいちばん安く済むかを、期待コストで比べるシミュレーターです。

各書の相場を入力すると、強化ごとに最安の選択肢が表示されます。

## 使い方

1. `index.html` をブラウザで開きます（ビルドやインストールは不要です）。
2. ラッキーデー書（+5%、+7%、+10%、+15%、+20%）の相場を m 単位で入力します。
3. 強化ごとの最安の選択肢と、使わない場合との差額が表示されます。

相場が空欄の書は比較に含まれません。

## 計算の考え方

書は試行のたびに1枚消費されるため、次の式で計算します。

```
期待総コスト = (強化コスト + 書の相場) ÷ 成功率
```

基本成功率は 6% で、書を使うとその分が加算されます。詳しくは [SPEC.md](./SPEC.md) を参照してください。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 本体（HTML・CSS・JavaScriptを1ファイルにまとめたもの） |
| `SPEC.md` | 仕様書（ルール、計算式、画面仕様、実装メモ） |
| `README.md` | このファイル |

## ゲームの数値を変更するには

`index.html` の `<script>` 先頭にある `BASE_RATE`、`STAGES`、`BOOKS` を編集します。

## GitHub Pages で公開する場合

1. リポジトリの Settings → Pages を開きます。
2. Source を「Deploy from a branch」にし、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。
